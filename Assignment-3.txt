# Conclusion

The zero-shot approach was able to correctly classify the message based only on the instructions provided in the prompt.

The one-shot approach included an example to demonstrate the expected classification pattern and response format. This provided additional context to the model.

The few-shot approach provided multiple examples of similar classification tasks. These examples gave the model a clearer understanding of the expected classification behavior and reasoning style.

In all three approaches, the message was classified as **Technical** because the payment was successfully completed, but the customer could not access the premium features.

The results demonstrate that examples can help guide the model's behavior and make the expected output pattern clearer. However, few-shot prompting is not necessarily better in every situation because it requires additional prompt tokens, and its effectiveness depends on the quality and relevance of the examples.
